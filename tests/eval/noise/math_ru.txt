Лемма 2. Для любого целого n больше 1 сумма первых n нечётных чисел равна квадрату n. Доказательство. Индукция по n. При n = 2 имеем 1 + 3 = 4. Пусть утверждение верно для n, тогда добавление следующего нечётного числа 2n + 1 даёт n в квадрате плюс 2n плюс 1, то есть (n + 1) в квадрате. Что и требовалось доказать.
