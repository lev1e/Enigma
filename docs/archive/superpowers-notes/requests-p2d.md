# Requests from P2D to P2C / others
1. ai_docedit.build_context (pptx): the context lines "Макеты: ...", and the per-slide ", макет Title and Content" suffix, and "Шрифты файла: ..." (layout names and font names from the template, e.g. "Title Slide", "Calibri") are sent through the leak guard and flagged (ORG x4, POSSIBLE_ENTITY x26 on a stock python-pptx deck). Result: sending an edit request on any normal pptx is blocked ("Sending blocked: unmasked data found"). Layout/font names are structural, not file content: exempt them from the guard or mask them before the check. P2D harness works around it by stripping those two lines in a monkeypatch only.
