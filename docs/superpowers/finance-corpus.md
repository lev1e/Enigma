# Finance workbook corpus

Evaluation workbooks for amount masking (`anonymizer/finance.py`). Two kinds, labelled explicitly: SYNTHETIC files are generated by `tools/make_finance_realistic.py` (`build_all()`), written by hand as OOXML so they carry what Excel itself saves (sharedStrings, custom numFmts, cached values, shared/array formulas, tables, names, CF, DV, comments + VML, drawings, charts with caches, hidden/veryHidden sheets, calcChain, docProps). No real company data. REAL files are public-licence downloads fetched by `tools/fetch_real_corpus.py` into the git-ignored `tests/eval/real/<id>/`.

Each synthetic workbook returns `secrets` (every planted amount, including those living only in CF / DV / names / comments / drawing / chart / format literal) and `money_cells` (key input constants); a masked output must contain none of the secrets.
