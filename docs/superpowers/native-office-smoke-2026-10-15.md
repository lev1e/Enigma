# Native macOS Office smoke

`tools/office_smoke_mac.py` creates nine uniquely named synthetic documents: source, edited and restored variants for DOCX, XLSX and PPTX. It uses the actual `docedit.outline` / `apply_patch` and `restore_ooxml` APIs. A changed or invented Name1 label must be refused, the permitted edit must preserve Name1, restoration must recover the synthetic original, and bold formatting must survive all three stages. The Excel fixture additionally retains a numeric control cell.

Run serially with the approved main-checkout Python, after the coordinator releases the diagnostic slot. `--prepare-only` validates source fixtures without opening applications. The default run opens the nine files in the installed Microsoft Word, Excel and PowerPoint applications, compares the expected document text/cell value through each app's scripting interface, then closes only the generated document without saving. Script terminology was checked against `/usr/bin/sdef` for all three installed apps and its included CocoaStandard dictionary.

The tool never reads a front/active document, enumerates other documents, quits apps, takes screenshots, changes preferences or certificates, installs add-ins, calls providers or accesses private case files. Word/Excel are opened read-only with recent-file insertion disabled. Every document reference uses its unique generated name and verifies its full path before reading content or closing. Each app subprocess is limited to 55 seconds; script cleanup only touches a verified generated reference. JSON output includes counts and numeric error codes, never script stderr or document contents.

Automation permission denial is reported with its numeric code. A timeout can mean an Office startup/licensing/permission dialog; the tool does not dismiss or claim to diagnose such a dialog. On a timeout, document cleanup cannot be confirmed and synthetic files are retained under the operating-system temporary directory with the prefix `AnonymizerOfficeSmoke-`. An application may retain its own synthetic document until the owner closes it. Successful runs remove synthetic files. This is evidence that real Office opens generated/edited/restored files; it does not verify the Office add-in UI, installer, signing or Windows integration.

Coordinator execution: preparation passed for all nine files, nine formatting checks and three protected-label checks. The actual Word, Excel and PowerPoint attempts each timed out with error -1712; zero application opens or closes were confirmed. Automation denial was not reported, but the cause of the timeout remains unverified. Synthetic files were retained; this is not a successful native Office or add-in verification.
