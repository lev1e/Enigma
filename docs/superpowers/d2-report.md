## Неверные или устаревшие утверждения в SECURITY.md (исправлены)

1. «Обращений к внешним серверам нет»: собранная программа раз в 12 часов читает ленту обновлений `latest.json` по HTTPS с GitHub (`updater.py`, `helper.py`). Выключателя в настройках не найдено.
2. Ключ устройства: «защищён DPAPI, перенести бесполезно» верно только для Windows. На macOS и Linux это открытый файл `device.key` (0600).
3. «Секреты в хранилище не записываются»: есть настройка `retain_secrets_for_restore` (по умолчанию выключена), при включении секреты сохраняются.
4. «Окно показывает страницу, которую обслуживает сервер того же процесса»: по умолчанию сервер в фоновой программе (`helper.py`); `--inprocess` только для разработки.
5. «Для docx, xlsx, pptx правка в файл не переносится» противоречило разделу о правке через JSON-патч: устарело, исправлено.
6. Дополнено: возвращённые версии хранятся 30 дней по умолчанию; точные имена файлов ключей ИИ (`ai_providers.bin`, `ai_<id>.dpapi`); токен add-in `X-Addin-Token`.

- Работа DPAPI, Keychain, Windows OCR, add-in в настоящем Office, установщик, настоящие провайдеры (как и в `status-2026-10-14.md`).
- Срок 7 дней копий add-in: взят из комментария в `addin.py`, константу срока не сверял.
- Шифрование `ai.bin`: подтверждено имя файла и docstring, не код записи.
- Утверждение о защите маршрута `/vendor/` ключом сеанса: общая проверка до маршрутов не прослежена отдельно.
- Упоминание в `SECURITY.md` картинок «вложенных в zip»: верхнеуровневые `.zip` отклоняются (`refusals.py`); относится ли это к архивам внутри docx, не прослежено.
- Что проверяют `tests/test_ws_gate.py` и `tests/test_ws_w9.py` в части `refusals`.
- Блокировка проверки обновлений: где-либо ещё, кроме `settings_schema.py`, выключателя искать не стал.
- Исходное содержимое `docs/features/*.md` выдержано в 35-70 строк; не везде достигнуто 40 строк.
