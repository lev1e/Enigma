# Enigma: логотип и иконки

Утверждённый знак: `packaging/icon/enigma-glyph.svg`. Светлая плитка имеет фон `#F4F7FC`, тёмная — `#080F24`. Готовые утверждённые экспорты находятся рядом: `Enigma-light.png`, `Enigma-dark.png` и соответствующие `.icns`. Не заменяйте знак старым изображением с капюшоном.

`tools/make_addin_icons.py` использует эти готовые PNG, без перерисовки знака. Он синхронизирует:

- значки Office 16/32/64/80/128 px и тёмные варианты;
- многоразмерный Windows `packaging/app.ico`, используемый приложением и Inno Setup;
- встроенные светлую/тёмную версии логотипа и favicon основного окна и ИИ-страницы;
- `docs/assets/logo-light.png`, `logo-dark.png`, совместимые имена `logo.png`/`logo-mark.png` для GitHub.

Основное окно и Office-панель выбирают плитку по светлой/тёмной теме. Значки ленты Office и встроенный Windows ICO используют светлую плитку с собственным фоном, читаемым на обеих темах. macOS bundle использует существующий утверждённый `Enigma-light.icns`; тёмный ICNS также сохранён в исходниках. Нативные иконки Finder/Explorer не объявляются автоматически меняющими тему.

GitHub README использует `<picture>` с двумя темами. Social preview и глобальный аватар аккаунта не меняются.

Обновление экспорта: сначала замените готовые PNG/ICNS утверждёнными версиями, затем выполните из корня `python tools/make_addin_icons.py`. Для изменения исходного SVG и регенерации плиток на macOS существует `tools/make_icon.py`; после него снова синхронизируйте потребителей. Windows и macOS release-сборки необходимо пересобрать после изменения ресурсов.
