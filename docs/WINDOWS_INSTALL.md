# Установка Anonymizer на Windows

Инструкция для обычного пользователя: без Python, без прав администратора.

> **Важно.** Эта инструкция составлена по коду установщика и программы. На настоящем компьютере с Windows и Office установка пока **не проверялась** (см. `docs/superpowers/windows-verification.md`). Если что-то выглядит иначе, чем здесь написано, это нормально: сообщите, что именно вы увидели.

## 1. Скачайте установщик

1. Откройте страницу релиза Anonymizer и скачайте файл `Anonymizer-Setup-<версия>.exe` (например, `Anonymizer-Setup-2.3.0.exe`).
2. Если рядом лежит файл `SHA256SUMS.txt`, проверьте, что установщик не повреждён и не подменён. Откройте PowerShell в папке «Загрузки» и выполните:

   ```powershell
   Get-FileHash .\Anonymizer-Setup-2.3.0.exe -Algorithm SHA256
   ```

   Сравните строку `Hash` с записью для этого файла в `SHA256SUMS.txt`. Они должны совпасть полностью. Если не совпали, не запускайте файл и скачайте заново.

## 2. Запустите установщик (SmartScreen)

Установщик пока **не подписан** цифровой подписью, поэтому Windows покажет синее окно «Windows защитила ваш компьютер» (Windows protected your PC):

1. Нажмите **«Подробнее»**.
2. Нажмите **«Выполнить в любом случае»**.

Права администратора не нужны: программа ставится в папку пользователя (`%LOCALAPPDATA%\Programs\Anonymizer`).

## 3. Мастер установки

1. Выберите «Далее» на первых шагах.
2. На шаге с дополнительными задачами два флажка:
   - **«Подключить к Word, Excel и PowerPoint (кнопка Anonymizer и работа в фоне)»**: включён по умолчанию. Оставьте его, если хотите работать из Office.
   - «Создать ярлык на рабочем столе»: по желанию.
3. Если на компьютере нет компонента **Microsoft Edge WebView2**, установщик поставит его сам (это нужно для окна программы). Нужен интернет только на этом шаге, если установщик не содержит загрузчик; тогда он предупредит об этом.
4. Нажмите «Установить», затем «Завершить». Можно сразу запустить Anonymizer.

### Запрос сертификата

Если вы оставили флажок про Office, Windows спросит, **доверять ли сертификату**. Это нормально и ожидаемо:

- Надстройка Office открывает локальную страницу `https://localhost`, которую отдаёт сама программа на вашем компьютере. Для HTTPS на этой странице программа создаёт собственный сертификат.
- Сертификат устанавливается на уровне вашей учётной записи (не для всего компьютера) и нужен только для адреса `localhost`.
- Нажмите **«Да»**. Если отказать, надстройка не откроется (см. «Если что-то не работает»).
- Убрать сертификат можно, удалив надстройку (раздел 6) или вручную: `certmgr.msc` → «Доверенные корневые центры сертификации» → «Сертификаты».

## 4. Перезапустите Word, Excel и PowerPoint

Закройте все окна Word, Excel и PowerPoint и откройте заново. Пока Office не перезапущен, кнопки нет.

В Office на вкладке **«Главная»** появится одна кнопка **Anonymizer** с логотипом. Она открывает панель с кнопками «Обезличить документ» и «Вернуть данные». Если кнопки на ленте нет, откройте **Вставка → Надстройки → Anonymizer**.

Anonymizer должен работать в фоне: пока надстройка подключена, закрытие окна программы только прячет его. Полностью выйти можно через меню профиля внизу слева → **«Выйти из программы»**. Автозапуск при входе в Windows включается вместе с надстройкой.

## 5. Если пропустили флажок: подключить позже

1. Откройте Anonymizer.
2. Нажмите значок профиля внизу слева (или Ctrl+,), выберите **Настройки**, затем раздел **«Word, Excel, PowerPoint»** (заголовок «Надстройка Word, Excel, PowerPoint»).
3. Нажмите **«Установить надстройку»**, подтвердите сертификат и перезапустите Office.

Статус в этом разделе: «Подключена», «Не подключена» или «Ошибка» с причиной. Тут же есть кнопка «Удалить надстройку».

То же из командной строки: `Anonymizer.exe --install-addin` (и `Anonymizer.exe --uninstall-addin`).

## 6. Удаление

1. **Параметры Windows → Приложения → Установленные приложения**, найдите Anonymizer, нажмите «Удалить».
2. Деинсталлятор сам удаляет надстройку из Office, автозапуск и сертификат. Перезапустите Office.

Если надстройку нужно убрать, а программа остаётся: Настройки → «Удалить надстройку».

## 7. Если что-то не работает

| Что случилось | Что делать |
| --- | --- |
| Кнопки Anonymizer нет в Office | Полностью закройте и снова откройте Word, Excel, PowerPoint. Проверьте в Anonymizer: Настройки → статус надстройки. Если «Не подключена», нажмите «Установить надстройку». Запасной путь: Вставка → Надстройки → Anonymizer. |
| Вы отказались подтвердить сертификат | Настройки → «Установить надстройку» и нажмите «Да» в запросе Windows. |
| Панель надстройки пустая или не загружается | Anonymizer должен быть запущен (он работает в фоне). Запустите его из меню «Пуск». Проверьте, что статус надстройки «Подключена». |
| Статус «Ошибка» и текст про порт | Надстройка использует локальный порт 47831. Если его занимает другая программа, закройте её или перезагрузите компьютер, затем перезапустите Anonymizer. |
| Организация запрещает надстройки Office | Политика компании может блокировать надстройки, не взятые из магазина. Обратитесь к администратору; обойти запрет программа не может. |
| Окно программы не открывается или просит WebView2 | Установите Microsoft Edge WebView2 Runtime (поиск: «WebView2 Runtime») с сайта Microsoft. |
| Антивирус ругается на установщик | Файл не подписан. Сверьте SHA256 (раздел 1) и обратитесь к тому, кто передал вам установщик. |

## 8. Что остаётся на компьютере

- Всё работает **без интернета**: файлы и соответствия не покидают компьютер. Надстройка обращается только к программе на самом компьютере (`https://localhost:47831`).
- Хранилище соответствий (файл `vault.bin`, зашифрованный) лежит в `%LOCALAPPDATA%\Anonymizer`. Деинсталлятор его не удаляет: так обезличенные ранее файлы можно будет восстановить после переустановки. Перед переустановкой Windows сохраните копию: Настройки → «Сохранить копию…».
- В той же папке (`%LOCALAPPDATA%\Anonymizer\addin`) лежат локальный сертификат и файл описания надстройки.

## 9. Статус проверки

Эта инструкция и установщик **не проверены на реальном компьютере с Windows и Office**. Список того, что должен проверить человек, ведётся в `docs/superpowers/windows-verification.md`.
