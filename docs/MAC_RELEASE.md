# Выпуск для macOS (Apple Silicon)

Сборка: `.venv312/bin/python tools/release_mac.py --base-url https://ХОСТ/ПАПКА --notes "Что нового"`
(окружение: Python 3.12 с уже установленными `requirements-build.txt`, включая Natasha и NumPy).
Старое `.build-venv-mac` не содержит NER; перед заменой артефактов скрипт проверяет модель и локальный Office.js.
Установку или скачивание зависимостей выполняют только после разрешения владельца.

Скрипт собирает помощников Apple Vision, `Anonymizer.app` (arm64, папочная сборка), подписывает ad hoc, гоняет самопроверку (включая загрузку NER в собранном приложении),
кладёт в `dist/release/`: `.dmg` (первая раздача), `.zip` (для обновления), `latest.json` (лента, подписана Ed25519).

## Выпуск новой версии
1. Поднять `__version__` в `anonymizer/__init__.py`.
2. Запустить скрипт, выложить все три файла в одну папку; `latest.json` должен лежать по постоянному адресу.
3. Лента: GitHub Releases репозитория `lev1e/Enigma`. `--base-url` = `https://github.com/lev1e/Enigma/releases/download/v<версия>`; адрес ленты зашит в `anonymizer/updater.py` (`DEFAULT_FEED_URL`, `.../releases/latest/download/latest.json`),
   Он должен быть прописан до сборки первой раздаваемой версии.

Ключ подписи: `~/.anonymizer-release/update-signing.pem` (вне репозитория; потеря = старые копии больше не обновятся,
сделайте резервную копию). Открытый ключ зашит в `updater.py`; тест `tests/test_updater.py` проверяет, что они совпадают.

## Ограничения
- Нет сертификата Developer ID: Gatekeeper спрашивает подтверждение при первом запуске (инструкция лежит в DMG).
  Обновления через программу ставятся без вопросов. Нотаризация (99 $/год) уберёт и первый вопрос.
- Только Apple Silicon. Intel Mac потребует отдельной сборки.
- Обновление работает из «Программы»; из DMG или Загрузок программа попросит переместить себя.
