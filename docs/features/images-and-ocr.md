# Картинки и распознавание текста (OCR)

## Что это

Картинки нельзя надёжно проверить автоматически: лица, подписи, печати, рукописный текст, снимки экрана и QR детектором не гарантируются. Поэтому по умолчанию любая картинка внутри документа (docx, xlsx, pptx, pdf, html, md) и отдельный файл PNG/JPEG заменяются целиком заглушкой с меткой `Image1`, `Image2`. Оригинал хранится в зашифрованном хранилище и возвращается при восстановлении. Метаданные (EXIF, XMP, миниатюры) не сохраняются.

## Режимы (`settings_schema.py`)

- `image_mode` = `replace` (по умолчанию): картинка заменяется целиком.
- `image_mode` = `redact_text` («Закрасить текст, картинку оставить (менее безопасно)»): картинка остаётся, текст, найденный OCR, закрашивается. Логотипы, лица и печати остаются видимыми; программа показывает предупреждение в настройках и в результате каждого файла.
- `ocr_images` (по умолчанию включено): распознавание действует только в режиме `redact_text`.
- `image_brand_policy`: `paint` (по умолчанию) закрашивает крупный текст, похожий на название, `warn` только предупреждает, `off` не ищет. Закрашенное название получает метку `Company`.

## Движки OCR (`anonymizer/ocr.py`)

Apple Vision (macOS, нужен готовый помощник или `swiftc`; исходники в `anonymizer/ocr_helpers/`), Windows OCR (через PowerShell и `Windows.Media.Ocr`), Tesseract (путь из `ANONYMIZER_TESSERACT` или `PATH`). Tesseract также используется как второй движок для сверки: латинские секреты мелким шрифтом пропускают Vision и Windows OCR. Штрихкоды и QR ищет только Apple Vision. Разрешение 300 DPI.

## Пределы

- Хранилище оригиналов картинок ограничено (по умолчанию 1024 МБ, `imagereplace.DEFAULT_STORE_LIMIT_MB`); при переполнении файл не выдаётся.
- Логотип, нарисованный в PDF векторно, заменить нельзя: закрашивается только прочитанное название, выводится предупреждение.
- Если надёжно обезличить картинку нельзя, файл не выдаётся. Четыре русских скана заблокированы по этой причине (`docs/superpowers/status-2026-10-14.md`).
- Windows OCR на настоящем Windows не проверялся; результаты Vision/Tesseract: `docs/superpowers/ocr-evaluation.md`.
- Картинки сжимаются до стороны 1600 пикселей для заглушки (`MAX_SIDE`).

## Где в коде

`anonymizer/imagereplace.py`, `anonymizer/ocr.py`, `anonymizer/imagetext.py` (нечёткое сопоставление, логотипный текст), `anonymizer/pdftext.py`, `anonymizer/formats.py` (`transform_image`, `transform_pdf`), `anonymizer/restore.py` (возврат картинок).
