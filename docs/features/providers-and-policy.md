# Провайдеры ИИ, политика и секреты

## Что это

ИИ-беседа в чате (по желанию, выключена по умолчанию). К провайдеру обращается только локальная программа; страница говорит с локальным сервером (CSP `connect-src 'self'`). Подробно о модели угроз: [../../SECURITY.md](../../SECURITY.md).

## Провайдеры

- Встроенные типы: `anthropic`, `openai`, `gemini`, `openrouter` и `custom` (`llm.KINDS`). Адреса по умолчанию - `llm.DEFAULT_BASE`.
- Свой OpenAI-совместимый адрес (`custom`): адрес, необязательный ключ, список моделей, галочка «внутренний сервер». Галочка - только метка «внутренняя/внешняя», ничего не защищает.
- Для чужих адресов нужен `https`; `http` разрешён только для `localhost`, `127.0.0.1`, `::1`. В адресе не может быть логина, пароля, параметров. Внешний `custom` без ключа отклоняется (`llm.validate`).
- Один запрос на сообщение: без повторов, без редиректов, ключ только в заголовке (`x-api-key`, `x-goog-api-key` или `Authorization: Bearer`), таймаут 60 с.
- Проверка подключения запрашивает список моделей (`llm.test_connection`, `list_models`).

## Выбор модели и источника файла

- Провайдер и модель выбираются списком в поле сообщения, запоминаются для каждого чата и меняются по ходу беседы.
- У каждого файла чата выбирается версия, которая уходит модели: «Обезличенный» (по умолчанию) или «Исходный». При исходной версии персональные данные не ищутся и не блокируют отправку, ответ показывается как есть; перед отправкой нужно подтвердить «Отправляются исходные данные: провайдер (внутренняя/внешняя)».
- Не более 3 файлов в сообщении, до 5 МБ файл, до 120000 знаков обезличенного текста, 20 последних сообщений истории (`ai_chat.py`).

## Секреты

Пароли, ключи, токены, строки подключения не уходят и в режиме исходных данных: значения заменяются на `[секрет удалён]` (`guard.strip_secrets`), итоговый запрос проверяется повторно (`secrets_left`). Распознаётся то же, что и в обычном режиме (слова-подписи, Bearer, JWT, приватные ключи, строки подключения, ключи вида `sk_live_...`); голый `sk-proj-...` без подписи может не находиться.

## Ключи API

Хранение (`keystore.py`): macOS - связка ключей через `security`, ключ передаётся по stdin; Windows - DPAPI (`ai_<id>.dpapi`); запасной путь - файл, зашифрованный ключом устройства (слабее). Список провайдеров лежит в `ai_providers.bin`. Страница получает маску (последние 4 знака). Ключ не попадает в резервную копию.

## policy.json

Необязательный файл администратора; программа только читает его при каждом запросе (`anonymizer/policy.py`).

- Путь: переменная `ANONYMIZER_POLICY`, иначе `%ProgramData%\Anonymizer\policy.json` (Windows), `/Library/Application Support/Anonymizer/policy.json` (macOS), `/etc/anonymizer/policy.json` (прочие).
- Схема (все ключи необязательны): `version`, `allow_originals_to_external` (bool, по умолчанию true), `allowed_hosts` (список строк; пусто - без ограничений), `providers` (список `{id, tier, base_url}`, `tier` - `internal` или `external`).
- Уровень провайдера по `id` или по точному `схема+хост+порт`; политика сильнее пометки пользователя.
- Файл есть, но не читается или неверен: исходные данные не уходят, остальные ключи игнорируются; причина в `policy.status()`.
- Файла нет: ограничений нет. Защиты от пользователя с правом записи в файл нет.

## Пределы

Проверено только на поддельном провайдере; реальные провайдеры, Keychain и DPAPI не проверялись. Add-in маршрутов ИИ не имеет.
