# История изменений

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/). Разделы: Добавлено, Изменено, Исправлено, Безопасность. Тег `v2.2.0` на GitHub указывает на старый коммит 25cad6b; границей версий служит коммит «Enigma 2.2.0» (7fd4dc4). Записи составлены по сообщениям коммитов; числа проверок лежат в `docs/superpowers/status-2026-10-14.md`.

## [2.3.0] - 2026-10-15

### Добавлено
- ИИ-провайдеры: свои OpenAI-совместимые адреса (в том числе внутренний «Тедорра»), метка «внутренняя/внешняя», выбор модели в строке сообщения, выбор версии файла для каждой отправки («Обезличенный» или «Исходный»), необязательный администраторский `policy.json` (P1).
- Правка файлов Office через ИИ: изменения текста и оформления в docx, xlsx и pptx показываются карточками «было, стало», применяются целиком или выбранными, каждое применение создаёт новую версию; предложения сохраняются в зашифрованных данных чата (P2A-P2E, S14). Проверено только на поддельном провайдере.
- Правка текстовых файлов по просьбе как новая версия файла (S10A).
- Панель просмотра файла справа: текст, markdown с подсветкой меток, таблицы со всеми листами, документы Word, слайды, страницы PDF, картинки; изменяемая ширина (S11A, S11C, S12C).
- Сторонние библиотеки панели (marked, DOMPurify, highlight.js) лежат в `anonymizer/web/vendor/`, перечень в `THIRD_PARTY_NOTICES.md` (S11C).
- Переработанное окно чата: закреплённая внизу строка сообщения, выбор файлов для сообщения, карточки файлов, переключатель файлов в панели просмотра (S10A, S10B, S13A, S13B).
- Установка add-in из программы: блок в окне, подсказка, которую можно скрыть, инструкция для Windows `docs/WINDOWS_INSTALL.md` (W9B2).
- Панель add-in использует цвета основного окна, показывает предупреждения о режиме картинок и нейросети (S9D).
- Нейросеть natasha как второй детектор имён: обучение по подтверждённым именам, подтверждение правилами, работа на размеченном markdown через маскирование (S8A, S8B, S9C, S9G).
- Новые виды данных: DEVICE_ID, MEDICAL_ID, COMPENSATION; год рождения отдельным правилом (S6C).
- Структура `docs/`: оглавление, архив рабочих материалов, `DEVELOPMENT.md`, этот файл.

### Изменено
- Интерфейс в сценарии «сначала обезличить»: одна зона перетаскивания, строка ИИ только после настройки, скрытый поиск (U1); у результата одна кнопка «Сохранить», строка открывает просмотр, остальное в меню «Ещё» (U2).
- Один источник номера версии: `anonymizer/__init__.py`; `pyproject.toml` и `packaging/version_info.txt` берут его оттуда; для сборки Windows добавлены контрольные суммы, исправлена кодировка UTF-8 в CI (W9A).
- Русские тексты ошибок и сообщений в чате и ИИ (S9E, S6E); увеличенные области нажатия, компактная строка сообщения на телефонах, фокус и тема (S9F, S6E).
- Ускорения без изменения результата (подтверждено сравнением отпечатков): быстрый путь нормализации, предфильтр правил, кэши, быстрый вывод нейросети (S7A, S8B, S9A).
- Проверка утечек в `eval_real` учитывает вхождения в исходном документе; базовые значения пересмотрены (14.10).
- Удалены неиспользуемые вендорные библиотеки (pdf.js, docx-preview, jszip, SheetJS, Split.js): 2,4 МБ стало 205 КБ (S12C).

### Исправлено
- Linux/Windows CI: зависимости окна, переносимые шрифты, ограничения длины UTF-8-имён, счётчик памяти Windows и сохранение байтов vendor-файлов при checkout.
- ИИ: разрешение спорного фрагмента привязано к отдельному вхождению и точному сообщению; выбор не распространяется на повторы и изменения текста.
- PDF: находка на стыке страниц больше не дублирует уже заменённый фрагмент; неоднозначные пересечения блокируются. Восстановление различает полные номера склеенных меток, собирает геометрически разделённые части и удаляет подписи только у известных изображений; семь проблемных публичных PDF прошли полный цикл без утечек с точным восстановлением содержимого.
- Предупреждение о сохранённых картинках Office показывается и при недоступном OCR; комментарии не принимают удалённые ранее элементы.
- Сборка macOS проверяет NER и Office.js заранее; самопроверка готового приложения загружает NER-модель.
- PDF: собственные склеенные метки не принимались за остаток и не запускали повторное распознавание (69-страничный PDF: 1317 с процессорного времени стало 63 с, S12A); повторяющиеся слова от распознавания поверх родного текста; ускорена закраска символов на больших страницах (S9B).
- Восстановление: цифра перед похожим на метку фрагментом не считается меткой (S12B); склеенные соседние метки; перерисовка чужого текста под рамками меток в PDF (S7B).
- PDF с `/JBIG2Globals` и `/Metadata` в картинках (S6A); подписи к картинкам рисуются после закраски текста, `Image7` больше не обрезается (S6D).
- Ложные срабатывания: заголовки форм не считаются организациями, соцсети не считаются людьми, общие фразы в кавычках не считаются проектами (S6C, S6D).
- Строгий режим скрывает повтор имени в начале предложения (S7C); настройки проверены тестом, убрано неиспользуемое поле (S7D).
- Вёрстка настроек и ИИ-чата на узких экранах (S6E).

### Безопасность
- Ключи вида `sk-proj-` и `sk-ant-` распознаются как секреты, в том числе при отправке исходных данных.
- Пароли, ключи и токены не уходят провайдеру ни в одном режиме.
- Картинки: режим «закрасить текст» помечен небезопасным, предупреждения о оставшихся пикселях и векторных логотипах (S6B).
- Для pptx не отправляются тексты макетов и мастеров (ложные срабатывания проверки) (P2E).
- Описание сети и пределов ИИ-чата в `SECURITY.md`, исходящая проверка покрыта тестом.

## [2.2.0]

### Добавлено
- Office add-in для Word, Excel и PowerPoint: кнопка на ленте обезличивает открытый документ на месте и возвращает данные, общие метки и хранилище с программой.
- Обезличивание и восстановление целой папки одним заданием.
- Фоновая программа (`main.py --serve`), которая держит хранилище и серверы; окно прячется по крестику, пока add-in подключён.

Запись составлена по заголовку коммита «Enigma 2.2.0: Office add-in, folders, background helper»; подробного описания у коммита нет.

## [2.1.0]

### Добавлено
- Параметры: скрывать сомнительные слова, скрывать страны, нейтральные имена выходных файлов.
- Компании и бренды без юридической формы, распространение на соседние упоминания, слова-подсказки, приоритет адресов (URL).
- Населённые пункты, сокращения названий филиалов, одна метка на место во всех падежах.
- Связывание ФИО латиницей и кириллицей; фамилии в списках.

### Изменено
- Названия должностей в виде прилагательных больше не принимаются за людей.
- Контейнеры Office безопаснее: удаляются миниатюра документа, встроенные данные диаграмм и OLE, названия тем нейтральные.
- Реальные термины для локальных проверок вынесены из репозитория.
